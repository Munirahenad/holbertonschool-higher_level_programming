# SQL - Introduction

---

## 📋 Description

This project is an introduction to **SQL** and **MySQL**.  
It focuses on understanding relational databases and performing basic SQL operations including database creation, table management, and data manipulation.

All tasks are executed using **MySQL 8.0** on **Ubuntu 22.04 LTS**.

---

## 🎯 Learning Objectives

At the end of this project, you should be able to explain:

- What a database is
- What a relational database is
- What SQL stands for
- What MySQL is
- How to create and delete a database
- The difference between DDL and DML
- How to CREATE and ALTER tables
- How to SELECT data from tables
- How to INSERT, UPDATE, and DELETE data
- How to use aggregate functions (COUNT, AVG, etc.)
- How to filter results using WHERE
- How to group results using GROUP BY
- How to sort results using ORDER BY

## 📁 Project Structure

| File | Description |
|------|-------------|
| 0-list_databases.sql | Lists all databases |
| 1-create_database_if_missing.sql | Creates `hbtn_0c_0` if it does not exist |

| 5-full_table.sql | Displays full table creation |
| 6-list_values.sql | Lists all rows from `first_table` |

| 8-count_89.sql | Counts records where id = 89 |
| 9-full_creation.sql | Creates `second_table` and inserts records |
| 10-top_score.sql | Lists records ordered by score DESC |
| 11-best_score.sql | Lists records with score >= 10 |
| 12-no_cheating.sql | Updates Bob's score |
| 13-change_class.sql | Deletes records with score <= 5 |
| 14-average.sql | Calculates average score |
| 15-groups.sql | Groups records by score |
| 16-no_link.sql | Lists records with non-NULL names |
