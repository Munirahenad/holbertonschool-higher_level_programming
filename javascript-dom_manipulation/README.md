# JavaScript DOM Manipulation

This project focuses on learning how to manipulate HTML elements using JavaScript and interact with web pages dynamically through the DOM.

## Description

In this project, we practice selecting HTML elements, modifying their content and styles, handling user events, and fetching data from external APIs using JavaScript.

The exercises demonstrate how JavaScript can update a page without reloading it, making web pages more interactive and dynamic.

## Learning Objectives

By completing this project, I learned how to:

- Select HTML elements using JavaScript
- Understand the difference between ID, class, and tag selectors
- Modify the style of HTML elements
- Get and update the content of HTML elements
- Add, remove, and toggle classes
- Create and insert new DOM elements
- Listen and respond to user events
- Fetch data from external APIs using the Fetch API
- Update the page dynamically without reloading

## Project Structure

- `0-script.js` — Changes the text color of the header to red
- `1-script.js` — Changes the header color to red when clicking on `#red_header`
- `2-script.js` — Adds the class `red` to the header when clicking on `#red_header`
- `3-script.js` — Toggles the header class between `red` and `green`
- `4-script.js` — Adds a new `<li>Item</li>` element to the list
- `5-script.js` — Updates the header text to `New Header!!!`
- `6-script.js` — Fetches and displays a Star Wars character name
- `7-script.js` — Fetches and lists all Star Wars movie titles
- `8-script.js` — Fetches and displays “hello” in French

## Concepts Used

### DOM Selection
The project uses:
- `document.querySelector()`

### DOM Manipulation
The project includes:
- Changing text content
- Changing CSS styles
- Adding classes
- Removing classes
- Toggling classes
- Creating and appending new elements

### Events
The project handles user interaction using:
- `addEventListener()`
- `click`
- `DOMContentLoaded`

### Fetch API
The project uses the Fetch API to:
- Request external data from APIs
- Convert responses to JSON
- Display fetched data inside HTML elements
