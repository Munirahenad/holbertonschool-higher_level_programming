# Python OOP Tasks

A collection of tasks and exercises to practice **Object-Oriented Programming (OOP)** concepts in Python, focusing on **file handling**, **JSON serialization/deserialization**, and a simple **mathematical algorithm**.

---

## Tasks

### Task 0: Read File
- **File:** `0-read_file.py`  
- **Description:** Reads a text file (UTF-8) and prints it to stdout.

### Task 1: Write to File
- **File:** `1-write_file.py`  
- **Description:** Writes a string to a text file (UTF-8) and returns the number of characters written.

### Task 2: Append to File
- **File:** `2-append_write.py`  
- **Description:** Appends a string at the end of a text file (UTF-8) and returns the number of characters added.

### Task 3: Convert to JSON
- **File:** `3-to_json_string.py`  
- **Description:** Returns the JSON representation (string) of an object.

### Task 4: Convert from JSON
- **File:** `4-from_json_string.py`  
- **Description:** Returns a Python object represented by a JSON string.

### Task 5: Save Object to JSON File
- **File:** `5-save_to_json_file.py`  
- **Description:** Writes an object to a text file using its JSON representation.

### Task 6: Load Object from JSON File
- **File:** `6-load_from_json_file.py`  
- **Description:** Creates an object from a JSON file.

### Task 7: Load, Add, Save
- **File:** `7-add_item.py`  
- **Description:** Adds all command-line arguments to a Python list and saves them to a JSON file.

### Task 8: Convert Class to JSON
- **File:** `8-class_to_json.py`  
- **Description:** Returns a dictionary description (simple data structure) for JSON serialization of an object.

### Task 9: Student Class
- **File:** `9-student.py`  
- **Description:** A `Student` class with a method to convert its attributes to JSON.

### Task 10: Student Class with Filter
- **File:** `10-student.py`  
- **Description:** An enhanced `Student` class with attribute filtering for JSON conversion.

### Task 11: Load Student from JSON
- **File:** `11-student.py`  
- **Description:** A `Student` class that supports serialization and deserialization (to/from JSON).

### Task 12: Pascal's Triangle
- **File:** `12-pascal_triangle.py`  
- **Description:** Returns Pascal’s triangle for a given integer.
