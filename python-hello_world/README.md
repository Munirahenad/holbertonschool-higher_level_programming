## Python Learning Project — 0x00. Python: Hello, World

This project includes beginner Python tasks that focus on printing output and working with strings (repetition, concatenation, and slicing).

### Tasks

**Task 0: Hello, print**  
- **File:** `2-print.py`  
- **Output:** `"Programming is like building a multilingual puzzle`

**Task 1: Print integer with string**  
- **File:** `3-print_number.py`  
- **Output:** `98 Battery street`

**Task 2: Print float with precision**  
- **File:** `4-print_float.py`  
- **Output:** `Float: 3.14` (formatted to 2 decimal places)

**Task 3: String repetition and slicing**  
- **File:** `5-print_string.py`  
- **Output:** prints `Holberton School` three times, then prints the first 9 characters (`Holberton`)

**Task 4: String concatenation**  
- **File:** `6-concat.py`  
- **Output:** `Welcome to Holberton School!`

**Task 5: String slicing (edges)**  
- **File:** `7-edges.py`  
- **Output:**
  - `First 3 letters: Hol`
  - `Last 2 letters: on`
  - `Middle word: olberto`

**Task 6: String extraction and concatenation**  
- **File:** `8-concat_edges.py`  
- **Output:** `object-oriented programming with Python`

**Task 7: The Zen of Python**  
- **File:** `9-easter_egg.py`  
- Prints **"The Zen of Python"** using a built-in Python feature (Easter egg).  
- **Constraint:** the script must be **98 characters maximum**.

### Requirements
- **Python:** 3.8.* (Ubuntu 20.04 LTS)
- First line of every script: `#!/usr/bin/python3`
- All files must be executable and end with a newline
- Code style checked with: `pycodestyle` (2.7.*)
